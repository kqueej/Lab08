## 1
Базовый случай, это когда метод перестает вызывать самого себя, чтобы проверить вывзов нужно просто увидеть, изменяется ли параметр в сторону условия

## 2
Каждый новый вызов метода помещается в стек вызовов, замершие вызовы ожидают результат

## 3
Сначала вызовы разворачиваются вниз, до базового случая

## 4
У рекурсии все вызовы в стеке

## 5
Логически смотреть, если условно в базовом случае n == 0, метод n + 1, то он не завершится

## 6
В глубоком вызове будет так

CountDigits(4) -- это текущий вызов
CountDigits(47)
CountDigits(472)
CountDigits(4725)
